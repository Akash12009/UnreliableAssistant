# POL-07 Battery Modules returns and approvals

POL-07 - Battery Modules returns and approvals. The return window for Battery Modules is 45 days from delivery. Orders exceeding $10,000 need sign-off by the Quality Director. Records must be kept 7 years. See [[SOP-07]] for handling steps.
