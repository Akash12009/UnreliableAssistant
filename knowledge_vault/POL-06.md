# POL-06 Lab Glassware returns and approvals

POL-06 - Lab Glassware returns and approvals. The return window for Lab Glassware is 21 days from delivery. Orders exceeding $10,000 need sign-off by the Safety Officer. Records must be kept 10 years. See [[SOP-06]] for handling steps.
