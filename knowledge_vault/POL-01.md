# POL-01 Beverage Equipment returns and approvals

POL-01 - Beverage Equipment returns and approvals. The return window for Beverage Equipment is 14 days from delivery. Orders exceeding $1,000 need sign-off by the Operations Director. Records must be kept 7 years. See [[SOP-01]] for handling steps.
