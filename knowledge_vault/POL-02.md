# POL-02 Cold Chain Reagents returns and approvals

Policy POL-02 governs Cold Chain Reagents returns and approvals. Customers may return Cold Chain Reagents within 21 days of delivery. Any single order above $2,500 requires written approval from the Quality Director. Return records are retained for 3 years. Handling follows [[SOP-02]].
