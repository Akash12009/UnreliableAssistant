# POL-04 Medical Consumables returns and approvals

POL-04 - Medical Consumables returns and approvals. The return window for Medical Consumables is 14 days from delivery. Orders exceeding $1,000 need sign-off by the Regional Manager. Records must be kept 5 years. See [[SOP-04]] for handling steps.
