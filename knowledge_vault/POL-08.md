# POL-08 Cleaning Solvents returns and approvals

Policy POL-08 governs Cleaning Solvents returns and approvals. Customers may return Cleaning Solvents within 21 days of delivery. Any single order above $7,500 requires written approval from the Regional Manager. Return records are retained for 7 years. Handling follows [[SOP-08]].
