# POL-05 Packaging Film returns and approvals

POL-05 - Packaging Film returns and approvals. The return window for Packaging Film is 60 days from delivery. Orders exceeding $10,000 need sign-off by the Quality Director. Records must be kept 3 years. See [[SOP-05]] for handling steps.
